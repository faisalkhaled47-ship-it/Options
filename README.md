# خياراتي — حاسبة عقود الخيارات

تطبيق ويب يُثبَّت على الشاشة الرئيسية للآيفون، يحسب التكلفة الحقيقية لعقود الخيارات الأمريكية للمستثمر السعودي:

- **الحاسبة:** التكلفة الكاملة بالدولار والريال، ونقطة التعادل بعد الرسوم، والحركة المطلوبة للسهم، ومنحنى الربح والخسارة، والإغريقيات (دلتا، ثيتا، فيغا، احتمال الانتهاء داخل المال) بنموذج بلاك-شولز، وتنبيهات تلقائية على أخطاء المبتدئين.
- **الرسوم:** جداول قابلة للتعديل لكل وسيط (سهم، أبيان، مخصص): العمولة والحد الأدنى، وORF وOCC وFINRA وSEC، وضريبة القيمة المضافة.
- **التحويل:** ريال↔دولار مع هامش الوسيط والرسم الثابت، وكم تودع لصفقة معينة.
- **السجل:** حفظ الصفقات وإغلاقها، وصافي الأداء بعد الرسوم، ونسبة الفوز، ودروس مستخرجة من سجلك.
- **تعلّم:** قائمة فحص قبل كل صفقة، وأسئلة، ومصطلحات، والضوابط الشرعية.

كل البيانات تُحفظ على جهازك فقط (localStorage)، ولا يُرفع شيء إلى أي خادم.
